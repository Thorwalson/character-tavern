🍺 Character Tavern Verwaltung ● Ungespeicherte Änderungen

1 · Verbindung zu GitHub

Veröffentlichen schreibt direkt in dein Repository – GitHub Pages aktualisiert die Seite danach automatisch (dauert ca. 1 Minute). Dein Token ist dein Admin-Zugang: ohne ihn kann niemand etwas veröffentlichen. Anleitung steht in der README.

2 · Reiter & Seiten

Zieh eine fertige HTML-Datei auf einen Reiter, um sie als Unterpunkt einzufügen – oder auf die Fläche ganz unten, um einen neuen Reiter zu erstellen. Reihenfolge per Ziehen am ⠿ ändern.

➕ HTML-Datei(en) hierher ziehen = neuer Reiter
oder klicken zum Auswählen

3 · Download-Bereich

Alle Seiten erscheinen dort automatisch. Hier kannst du zusätzliche Kategorien mit beliebigen Dateien anlegen – Datei ins Feld ziehen, Download-Button entsteht von selbst.
